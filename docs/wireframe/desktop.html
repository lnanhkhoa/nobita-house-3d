Hit-testing. .ui-root is pointer-events:none; only the rail, controls, card, pins and the credits link opt back in. .pin-layer stays none so the empty 90 % of it never steals an orbit drag; .pin__label is none too — a 260 px wide label with auto would carve a dead strip across the diorama. Occluded pins drop to pointer-events:none + aria-hidden + tabindex="-1". No scrim on desktop, so the model is still orbitable while the card is open.
Shown states. Pin 1 active (accent fill, pulse off, label pinned) · pin 3 keyboard-focused (2 px accent ring + 4 px white halo) · pin 5 label flipped near the right edge · two occluded ghosts · Cutaway toggle in hover · Roof and 2nd Floor in aria-pressed="true".
